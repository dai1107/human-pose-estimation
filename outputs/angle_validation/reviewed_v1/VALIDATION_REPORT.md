# 八动作人工角度验证报告

## 数据范围

- 人工报告：`angle_validation_report_v1.json`
- 10 段视频，8 个动作，150 条角度标注
- 视角：正面 55 条、侧面 61 条、斜后方 34 条
- 可见度：高 127 条、中 20 条、低 3 条
- Full 模型有效匹配 149 条；未匹配 1 条为 `phone_burpee_broad_jump_006` 第 0 帧左肘，该帧姿态缓存无有效关节结果

## 已修复问题

3D shadow 链路中的 2D 对照角原先直接使用归一化坐标计算，未按原视频宽高还原像素比例。对本批 720×1280 竖屏视频，这会显著扭曲角度，并影响 2D/3D 冲突判断。

修复后，帧宽高已贯通上传视频、Web 实时、桌面实时和模型分层验证入口。Full 2D 的总体 MAE 从 25.9922° 降至 15.5292°，下降 10.4630°（40.25%）。

## 3D 结论

人工标注定义是原视频像素平面的 A-B-C 投影角，不是空间 3D 真值。因此报告中的 3D 数字只能称为“相对人工 2D 的投影一致性差”，不能称为 3D 角度误差。

当前 3D 继续保持 shadow/置信度辅助策略，不用这批 2D 标签拟合 3D 校准参数，也不允许 3D 单独把正式 2D 判定提升为有效。要正式验证 3D，需要多视角标定、深度骨架或动作捕捉提供空间关节点真值。
