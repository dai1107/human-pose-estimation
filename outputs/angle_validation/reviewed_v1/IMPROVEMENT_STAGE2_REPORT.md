# 角度改进第二阶段报告

## 实现结果

本阶段遵守“不增加姿态推理、不修改 HYROX 计数/判罚输入”的约束：

1. 可靠的 world-3D 角度仍作为显示首选。
2. world-3D 缺失或被质量门控拒绝时，使用已按原视频宽高纠正的高置信 2D 角度显示。
3. 2D 三点最低置信度为 0.70；低可见度、低存在度、图像关节缺失或无效几何时不显示角度。
4. 2D 回退仅用于界面和报告显示，不修改动作分析器接收的 `rule_angle_deg`，不改变现有动作状态机。
5. 上传性能报告新增 `analysis_speed_ratio` 和 `normal_speed_analysis_passed`，可直接判断分析速度是否达到视频原始 FPS。
6. 已复审 RGB 指导评估入口同步传入原视频宽高，线上主链、模型分层验证与离线 shadow 证据现在使用同一套宽高比修正语义。

## 正常速度实测

测试视频：墙球下蹲不足，720×1280，30 FPS，345 帧。使用 Full 模型、冷姿态缓存，完整走生产上传分析链路。

| 指标 | 结果 |
|---|---:|
| 原视频 FPS | 30.000 |
| 分析 FPS | 40.569 |
| 速度倍率 | 1.352× |
| 实时速度检查 | 通过 |
| P50 单帧总耗时 | 21.511 ms |
| P95 单帧总耗时 | 35.807 ms |
| 姿态推理次数 | 345 / 345 帧 |
| 新增 2D 回退显示 | 145 个角度 |
| 可靠 3D 显示 | 545 个角度 |

上传视频仍然按“尽快完成分析，然后浏览器按原视频时钟正常播放”的方式工作，不会人为限速，也不会重复推理。

实测产物：`outputs/benchmarks/upload_normal_speed/1785762891498016500/normal_speed_benchmark.json`。

## HYROX 兼容性

- 完整自动测试：712 项通过。
- 角度展示选择发生在 `analyzer.update(...)` 之后，不会反向修改计数、阶段或判罚特征。
- 2D/3D 冲突仍只允许降低置信度，不能把原本无效的动作提升为有效。

八动作 golden 在当前代码与当前 MediaPipe 环境中为 5/8。通过：箭步蹲、滑雪机、墙球、划船机、农夫行走。未通过：波比跳、推雪橇、拉雪橇。三个失败动作独立重跑后稳定复现。

Golden 验证入口只执行 MediaPipe、平滑、`extract_basic_pose_features` 和动作分析器，不调用本阶段新增的角度显示选择逻辑；本次也未修改对应动作分析器。因此该结果记录为“冻结期望与当前模型输出的既有漂移”，没有通过放宽期望或改动计数规则来掩盖。
